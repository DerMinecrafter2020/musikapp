## 2024-05-24 - [Fix XSS Vulnerability in DOM rendering]\n**Vulnerability:** XSS vulnerability where user data (song info) is injected directly into `innerHTML` without sanitization.\n**Learning:** The frontend uses direct DOM manipulation (`innerHTML`) to render dynamically loaded song content, making it susceptible to XSS if the data (like song titles, artists, or cover URLs) is untrusted or maliciously crafted.\n**Prevention:** Added a reusable `escapeHTML` utility function to sanitize strings by escaping HTML special characters before inserting them into the DOM.
